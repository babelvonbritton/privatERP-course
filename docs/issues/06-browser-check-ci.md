# Issue 6: The browser check is not wired into CI

- Category: `enhancement`
- State: `ready-for-agent`
- Severity: nice to have (Ponytail audit v1.0.6, finding 6)

> *This was generated by AI during triage.*

## Problem

`npm run verify:browser` runs 114 Playwright checks against the built site,
but the deploy workflow only runs type check, tests, and build. The browser
suite only runs when someone remembers to run it, so a UI-only regression
ships green.

## Fix

Add a CI job that builds, serves the output folder, installs Playwright
Chromium, and runs the browser check, so UI-only regressions cannot ship
green. Validate the workflow YAML (parse it; if a YAML parser is available,
use it).

## Acceptance

- The deploy workflow runs the browser check on every push and pull request.
- The workflow YAML parses cleanly.
- The deploy job still only deploys outside pull requests.
